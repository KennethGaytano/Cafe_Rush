# Project Instructions

-   Always check `PROJECT_PROGRESS.md` before making changes to the
    project.
-   Do not add, remove, modify, or reorganize anything in the project
    unless the user explicitly asks you to do so.
-   If you believe an additional change or feature would be useful but
    the user has not requested it, explain the suggestion and ask for
    approval first.
-   Treat the user's current request as permission only for the changes
    needed to complete that request. Do not make unrelated changes.
-   Keep `PROJECT_PROGRESS.md` accurate when the user asks you to update
    project progress.
